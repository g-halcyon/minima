Minima — Ultra-Fast Native Browser

Minima eliminates web framework bloat by running lightweight native C++ code directly against system webviews (WebView2, WebKitGTK, WKWebView, Android WebView).

✦ On-Device Intelligence Active

The docked sidecar reads page content and streams Gemma 3 1B responses instantly without transmitting telemetry or analytics off-device.

✦ Ask This Page On-Device
Summarize what makes Minima fast?
✦ Minima AI: Minima avoids Electron/Tauri runtimes by binding portable C++17 logic directly to native OS webviews, resulting in sub-120ms launch times.

Engineered for Extreme Performance

A single portable C++17 core driving native OS webviews across desktop and mobile.

Zero Framework Bloat

One small, hyper-optimized C++ executable. No Electron, no duplicated Chromium runtimes, and zero JavaScript frame overhead.

On-Device Local AI

Embedded sidecar engine running small Gemma models locally. Powers natural language command palettes (Ctrl+K) and instant page summarization.

Network-Level Adblock

Built-in tracker and ad prevention operating natively at network layer with live shield block counters.

Command Palette (Ctrl+K)

Keyboard-driven natural language command bar. Perform actions, query tabs, or ask quick AI questions with one keystroke.

Shared C++17 Core

Architecture splits cleanly into a portable C++ core and thin OS native shells across Windows, Android, Linux, and macOS.

Private Mojeek Search

Default integration with Mojeek, the privacy-first search engine that does not track your browsing history or queries.

Cross-Platform Availability

Native shells binding to the system webview on every operating system.
